# OSGED Web (Frontend)

ส่วนหน้าจอผู้ใช้งาน จัดการด้วย pnpm

---

## การเตรียมระบบ (Setup)

1. ติดตั้ง Dependencies:
   pnpm install

---

## การรันระบบ (Execution)

1. รันเพื่อพัฒนา (Development):
   pnpm run dev

2. การ Build สำหรับใช้งานจริง:
   pnpm run build

---

## หมายเหตุ
ตรวจสอบให้แน่ใจว่าได้เปิดใช้งาน OSGED_backend เรียบร้อยแล้วก่อนเริ่มรันส่วนของ Web เพื่อให้การเรียกใช้ API ทำงานได้ถูกต้อง
